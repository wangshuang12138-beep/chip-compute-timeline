# 从晶体管到算力网关 · 芯片与算力硬件演化史

交互式时间轴：八十年芯片演化，二十年算力搬家（云 → 边缘 → 网关）。

**在线访问**：https://wangshuang12138-beep.github.io/chip-compute-timeline/

## 特性

- **可播放的时间轴**：播放头自动扫过 1947–2026，三条泳道（芯片 / 板卡·模组 / 一体机·设备）节点依次点亮
- **模型参数规模感知**：顶部仪表实时显示"当前可跑模型规模上限（B 参数）"，从 CV 时代一路跳到 70B
- **数据可溯源**：每个数据点附官方出处链接，底部有完整数据底表
- **零依赖单文件**：原生 HTML/CSS/JS，无构建步骤，GitHub Pages 直接托管

## 交互

| 操作 | 效果 |
|------|------|
| ▶ / 空格 | 播放 / 暂停 |
| ⟲ | 回到 1947 |
| 点击进度条 | 跳转 |
| 拖动时间轴 | 精确 scrub |
| 点击节点卡片 | 打开官方出处 |

## 模型规模估算口径

基于 INT8/INT4 量化推理的社区经验值（约 2 TOPS/B 参数起），仅作量级感知，非厂商标称。详见页面底部说明。

## 数据核查

所有硬件规格与发布时间以官方出处为准，核查记录见 `fact-check` 提交历史。
